3D JEPA World Model Driven
Multi-Node Semantic Communication

Paper arXiv Code

Interactive 3D demo on held-out scenes. Drag to rotate, right-drag to pan, scroll to zoom, space to play.

Overview

UAVs, vehicles and roadside units observe the same 3D scene and send semantics to an edge fusion centre over block fading uplinks. Each node runs an RGB-D encoder and a light head; it sends Slepian–Wolf coded class decisions on a digital layer and a variable number of task-subspace measurements of its JEPA latents on an analog layer. The centre keeps a 3D world state in information form, predicts every token with a JEPA predictor before the frame arrives, decodes both layers with this prediction as side information, and broadcasts an uncertainty map that tells the nodes where to spend the analog measurements.

Demo

  • Semantics: camera images, ground truth, node decisions, the world-model prediction made before the frame is received, the fused result and its errors.
  • Transmission: the uncertainty map broadcast by the centre, the analog measurement rows of each token, the decisions that reach the centre, and the JEPA prediction error.
  • One model is used for all SNRs (−5, 0, 10 dB) and bandwidths (1, 1/4, 1/16 complex channel uses per token). Hover a camera view for the values of a token. On a slow connection playback streams half resolution; a paused frame is shown at full resolution.

Data

The wide-area 5-UAV and near-spacing 3-UAV scenes are rendered in AirSim city environments; the vehicle-to-everything scenes are from V2X-Sim 2.0 (Li et al., RA-L 2022).
